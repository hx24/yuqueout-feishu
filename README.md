# YuqueOut → Feishu

Chrome Extension (Manifest V3) for one-time, one-way migration from Yuque knowledge bases to editable Feishu Docs, based on [YuqueOut](https://github.com/Navyum/chrome-extension-yuque).

See source files, integration script and GitHub Actions build after initial setup. Authentication and real Feishu import must be validated with a pilot before migrating important content.
